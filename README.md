## Freelance Rate Calculator
**File:** `rate_calculator.py`

Asks for your monthly income goal, hours per week, and weeks per month — then calculates the hourly rate you need to charge to hit your goal.

### How to run it:
1. Make sure Python 3 is installed
2. Download `rate_calculator.py`
3. Run `python3 rate_calculator.py` in your terminal
4. Answer the questions and get your rate!
